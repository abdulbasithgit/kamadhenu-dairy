# Sri Chettinadu Kamadhenu Dairy Farm – website

Next.js (App Router) + TypeScript + Tailwind CSS v4. English and Tamil.

## Run locally

```bash
npm install
npm run dev          # http://localhost:3000  (opens /en/ or /ta/)
npm run build        # static export into /out (served from "/")
npm run build:pages  # static export with the GitHub Pages base path /kamadhenu-dairy
npm run serve        # serve /out locally (after npm run build)
npm run lint         # ESLint
npm run format       # Prettier
npm run i18n:review  # refresh the Tamil review list at the bottom of this file
```

### Business details (`src/data/site.ts`)

- Leave a field **empty** until you have the real value. Empty fields are **hidden on the
  site automatically** (no "TODO" is ever shown to visitors).
- `url` – the site address used for every canonical link, Open Graph link and the
  sitemap. It is the GitHub Pages preview address for now;
  **change it to the real domain at launch.**
- `serviceArea` – the main town you deliver to ("homes in and around Karaikudi").
  Keep it in line with `deliveryAreas`.
- WhatsApp: until `contact.whatsapp` is filled in, WhatsApp buttons still open WhatsApp with
  the message, but the visitor has to pick the chat. **Fill this in first.**
- All `tel:`, `wa.me` and `mailto:` links are built by `src/lib/contact.ts`
  (`telHref()`, `whatsappHref(message)`, `mailtoHref()`) – never type them by hand.
- `orderSheetEndpoint` comes from the `NEXT_PUBLIC_ORDER_SHEET_URL` environment variable
  (locally: a `.env.local` file; on GitHub: an Actions **variable** named `ORDER_SHEET_URL`).

## Colour options (A / B)

One setting in `src/data/site.ts`:

```ts
colorTheme: "light-green", // Option A (default): cream + soft sage sections, forest green footer
colorTheme: "rich-green",  // Option B: forest green hero, stats and footer; sage elsewhere
```

Change the value, commit and push – the preview link updates in about a minute.
Navy and gold stay for the logo, headings, buttons and borders in both options.
All text/background colour pairs were checked for WCAG AA contrast.

## Languages (English / Tamil)

- URLs: `/en/…` and `/ta/…`. The site root `/` opens the visitor's last chosen language
  (remembered in the browser), otherwise English.
- The header (and mobile menu) has a language switch that keeps you on the same page.
- **Every visible string lives in `en.json` / `ta.json`. Components contain no text.**
  `ta.json` must have every key in `en.json` – the build fails otherwise.
- New pages (Phase 3 onwards) must add their English **and** Tamil text.
- Pages not built yet show a translated "Coming soon" page. When a real page is built,
  remove it from `comingSoonPages` in `src/data/navigation.ts`.
- Brand names (Sri Chettinadu Kamadhenu Dairy Farm, Kamadhenu, A2, WhatsApp) stay in English.
- Tamil tone: **headings** (titles, eyebrows, card titles) in semi-formal standard Tamil
  ("எங்கள்", "மண்ணில்", "அக்கறையுடன்"); **body text** friendly and conversational.
- No "TODO" text ever reaches visitors. Unfinished text is left empty and the section shows a
  tidy fallback (e.g. "Our story is coming soon") or is hidden. Every build runs
  `scripts/check-content.mjs`, which fails if any page shows "TODO" or an unfilled `{placeholder}`.
- Tamil review spreadsheet: `docs/tamil-review.csv` (key, English, Tamil, page, status –
  grouped by page). Regenerate it with `npm run i18n:review` after any text change.

## Preview deployment (GitHub Pages)

Every push to `main` builds the site and deploys it with `.github/workflows/deploy.yml` to:

**https://abdulbasithgit.github.io/kamadhenu-dairy/**

One-time setup on GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

How it works:

- `next.config.ts` uses `output: "export"` (plain static files in `/out`).
- On Pages the site lives under `/kamadhenu-dairy`, set via the `NEXT_PUBLIC_BASE_PATH`
  env variable (only in the workflow and `npm run build:pages`; empty for `npm run dev`).
- `next/link` adds the base path automatically. **`next/image` does not** – always write
  `src={withBasePath("/images/…")}` (from `src/lib/basePath.ts`).
- Dynamic routes (e.g. `products/[slug]`) must export `generateStaticParams()` and
  `dynamicParams = false`.

### Preview mode (switch off at launch)

`previewMode` in `src/data/site.ts` controls, in one place:

- `<meta name="robots" content="noindex, nofollow">` on every page
- `robots.txt` → `Disallow: /`
- the dismissible "Preview version – for review only" banner

Set it to `false` for the real launch.

(Full deploy steps for the real launch are added in Phase 6.)
